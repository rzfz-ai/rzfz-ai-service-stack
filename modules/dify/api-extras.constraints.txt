# api-extras.constraints.txt — exact pins for every package the #1981 extras
# add to upstream's dify-api venv (modules/dify/Dockerfile.api, steps 2-4).
# =============================================================================
# The build passes this file as a uv constraint to the extras install and the
# opencv swap, then fails if ANY package it added (or moved) is not listed here
# with its exact version. torch/torchvision are pinned by the TORCH_VERSION /
# TORCHVISION_VERSION build ARGs instead. Without this file the closure floats:
# unstructured-inference has no upper bound, and its first release needing a
# newer torch would pull PyPI's CUDA build on every online upgrade that day.
#
# Resolved for Dify 1.17.1 (unstructured 0.27.5), cp312 linux, extras
# pdf,image,xlsx,pptx,docx, torch 2.10.0+cpu (2026-10-05). pandas, protobuf
# and onnxruntime are upstream packages the extras must move (see the
# Dockerfile, step 0); opencv-python is installed and then swapped for the
# headless wheel of the same version. en-core-web-sm is the spaCy model
# unstructured would download at run time (#2073, Dockerfile step 3b); it is
# installed from its sha256-checked wheel with --no-index, never resolved.
#
# NOTE 2026.11: Dify 1.18.0 moved the base to Python 3.13; the pins below are the
# 1.17.1 / cp312 resolution and are NOT yet re-resolved for 3.13 (no Docker where
# the bump was made). A build that finds a package unpinned or moved fails closed.
#
# Regenerate after a DIFY_VERSION, TORCH_VERSION or UNSTRUCTURED_EXTRAS change,
# on a build box with network. The regen build is unpinned, so it goes under a
# THROWAWAY tag, never the shipped razzfazz-dify-api:<version> (a box that
# stopped halfway would run it, and the build record would call it current):
#   docker build --build-arg DIFY_VERSION=${DIFY_VERSION:-1.17.1} \
#     --build-arg API_EXTRAS_REGEN=1 -t razzfazz-dify-api:regen \
#     -f modules/dify/Dockerfile.api modules/dify
#   { grep '^#' modules/dify/api-extras.constraints.txt; \
#     docker run --rm --entrypoint cat razzfazz-dify-api:regen \
#       /opt/razzfazz/api-extras.resolved.txt; } > /tmp/pins && \
#     mv /tmp/pins modules/dify/api-extras.constraints.txt
#   docker image rm razzfazz-dify-api:regen
#   docker compose build dify-api      # the shipped tag, with the new pins; must pass
