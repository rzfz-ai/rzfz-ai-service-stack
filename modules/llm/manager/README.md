# LLM Manager (manager) — #254 Phase 1

Sovereign, Kubernetes-free control plane over a heterogeneous LLM fleet
(CUDA / AMD Strix Halo / Mac). This module is the **manager** (`llm-manager`)
plus a **LiteLLM pure router** (`llm-manager-router`). It is the strategic
exit from GPUStack.

Authoritative spec: `internal-docs`
Task breakdown: `internal-docs`

## Phase-1 scope (this module)

Gateway + **token-only** chargeback MVP:

- **Auth** (`app/auth.py`): `rzfz-sk-…` bearer → SHA-256 key_hash → Valkey cache →
  Postgres fallback → request context (cost-center, allowed models, limits).
- **Enforcement** (`app/enforce.py`): active · model-allowed · rpm/tpm Valkey
  sliding window (403 / 429).
- **Streaming proxy** (`app/proxy.py`): httpx SSE passthrough to LiteLLM; forces
  `stream_options.include_usage=true`; hybrid-bypass hook (interface).
- **Metering** (`app/metering.py`): parse the final usage chunk → **input /
  output / cached** token counters → `usage_events` (async, never blocks the
  stream). Tokenizer backstop when the engine omits `usage`.
- **Keys / cost-centers + report** (`app/api/keys.py`): CRUD + per-key token
  usage over a window (`SUM(tokens) GROUP BY api_key, window`). **No currency.**
- **/metrics** (`app/metrics.py`): Prometheus business metrics —
  `orchestrator_tokens_total{cost_center,type=input|output|cached}`, failover,
  proxy latency, active keys. No currency.
- **Router config generation** (`app/router_config.py`): renders the LiteLLM
  `model_list` from manager state (pure router — no keys/spend in LiteLLM).

> **Chargeback is TOKEN-ONLY** (operator 2026-08-10): input / output / cached
> tokens per API key per window. **No euros, no GPU-hours, no `model_pricing`
> table, no `cost` column** anywhere.

## Data model

`llm_manager_db` on the shared Postgres (per-service-DB pattern). SQLAlchemy
models in `app/models.py`; Alembic migrations in `alembic/versions/`.
`alembic upgrade head` is run by `entrypoint.sh` on every start (idempotent).

## Not in Phase 1

- **D1** AMD data plane (`llama-swap` + patched `llama-server` Vulkan on gfx1151)
  — bench-box work; a first-cut single-model serve is the G1 proof.
- **Phase 2**: `llm-worker-agent` (worker agent), the scheduler (deployments →
  instances, replicas, per-track artifact resolution, rolling update), Tier1↔2
  model distribution, CUDA node (`vllm/vllm-openai`), Prometheus target-gen.
- **Phase 3**: hub/entitlement broker, dual-source catalog UI, Wazuh, HA.

## Local development / tests

Unit + API tests run off-box against an ephemeral Postgres:

```bash
rzfz test llm-manager --unit --api
# or targeted:
tests/.venv/bin/python -m pytest tests/unit/llm-manager tests/api/llm-manager -p no:cacheprovider
```

The app package is import-safe off-box (no DB/Valkey/log side effects at import).

## Enable on a box

```ini
# .env
COMPOSE_PROFILES=...,llm-manager
LITELLM_INTERNAL_KEY=<random>
LLM_MANAGER_DB_PASSWORD=<random>
```

The router reads `router-config.yaml` (generated by the manager) from the shared
`llm-manager-router-config` volume.
