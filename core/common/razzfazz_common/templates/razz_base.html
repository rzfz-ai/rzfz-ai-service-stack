Block API (stable; bumping requires an M-slice): title — text (defaults to service_name | 'rzfz.ai') favicon — favicon href (defaults to /branding/media/...) extra_css — additional <link rel="stylesheet"> tags extra_head — anything else inside <head> (meta, inline <script>, etc.) body_attrs — extra attributes injected into <body ...> (raw string) header — top-of-page header markup (logo, top-nav, etc.) layout — page chrome between header and footer; default wraps `content` in .razz-container (max-width 1100px).
