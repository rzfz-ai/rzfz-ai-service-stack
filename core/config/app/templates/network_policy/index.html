Network Policy

The ACTUAL per-container network policy of this box — introspected live from docker.

What this shows: network-level reachability — two containers on a shared docker network can reach each other by name (not observed traffic). The internet column is the egress posture, derived from each container's networks + proxy env: DIRECT = attached to a WAN-capable docker network (usually the shared default bridge) — it can egress, not that it observably does; via SSRF proxy = routed through caddy:8195; NONE = only on internal networks, no direct path out. Box mode: {{ model.box_mode }}{% if model.box_mode == 'offline' %} — egress is suppressed at the app layer, not firewalled.{% endif %}
A stock stack puts most services on the flat default bridge with no per-service egress filtering, so most read DIRECT by design. The summary below collapses that majority and leads with the exceptions. Editing this policy and the userdefined mode arrive in a later release.  ·  Offline / Network status →
