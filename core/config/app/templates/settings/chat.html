Forward user info headers {% if config.forward_user_info_headers %}On{% else %}Off{% endif %}

Warning: Open WebUI then sends each user's id, name, e-mail and role to EVERY model connection configured in Open WebUI, including external providers. Required for per-chat session affinity.

With forwarding on, Open WebUI also names the chat in each request, and the LLM Manager keeps a chat's turns on one replica so its prompt cache is reused. The LLM Manager reads only the chat id; it neither logs nor forwards the user fields. With forwarding off, every turn is balanced on its own. Session affinity itself is switched in the LLM Manager console (Settings → Routing).

Saving a change recreates Open WebUI{% if not chat_enabled %} — the Chat module is disabled, so the value is only stored and applies when it is enabled{% endif %}. Stored as OWUI_FORWARD_USER_INFO_HEADERS in .env; upgrades keep it.
