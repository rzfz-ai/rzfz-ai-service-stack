Model source

The file is validated (GGUF magic) before anything is written. Very large uploads may exceed the portal's request timeout — for those, stage the file on the box and use the "Path already on the box" option.

The path must be readable by the razzfazz-config container — stage the file under the stack directory ({{ stack_root }}), or a directory bind-mounted into razzfazz-config (e.g. a mounted USB).

Registration

The name GPUStack exposes this model as (e.g. on /v1-openai/models).

Registered models land in {{ local_models_dir }} inside the gpustack volume and count toward rzfz verify-models. Registration uses restart_on_error: false.
